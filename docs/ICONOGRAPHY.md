# Iconografia e marchio

## Icona ufficiale

Gli asset ufficiali sono:

- `assets/slide_narrator_icon.png`;
- `assets/slide_narrator_icon_sidebar.png`;
- `assets/slide_narrator_icon.ico`;
- `assets/slide_narrator_logo.png`.

Non ridisegnare, reinterpretare o ricostruire l'icona tramite AI o forme QML. Non modificare proporzioni, colori, onde sonore, microfono o diapositiva.

## Dimensioni d'uso

| Contesto | Dimensione consigliata |
|---|---:|
| Finestra / taskbar | asset nativo multipla risoluzione |
| Testata sidebar | 36–40 |
| Pagina Informazioni | 72–96 |
| Schermata iniziale | 96–128 |

Non usare il logo completo come icona di attività, voce o tecnologia.

## Icone di navigazione

- stile lineare;
- monocromatiche;
- 20 × 20;
- spessore coerente;
- allineamento ottico, non soltanto geometrico;
- testo sempre presente in modalità espansa;
- tooltip in modalità compatta.

## Icone di file e tecnologie

- 24 × 24;
- semplici e riconoscibili;
- colore consentito;
- evitare la mescolanza di loghi fotografici e icone lineari;
- usare marchi commerciali solo quando necessario e secondo le rispettive regole.

Pittogrammi interni consigliati:

- FFmpeg: pellicola + onda;
- LibreOffice: documento + conversione;
- Edge TTS: onda sonora + nube/connessione;
- PowerPoint: diapositiva arancione.

## Formati

- SVG per comandi e navigazione;
- PNG per il logo ufficiale quando necessario;
- ICO multi-risoluzione per Windows;
- nessun file font usato come icon font;
- ogni SVG deve avere un nome semantico e un `viewBox` coerente.
